# The Holistic Student: Social-Emotional Learning in K-12 Education

> MEITE Final Project · Kiannah Pierce · University of North Carolina · 2026

## About

This ePublication explores the Social-Emotional Learning (SEL) industry — from its ancient roots to its evolution into a multi-billion dollar technology-driven sector. It features an in-depth analysis of the SEL market, a business profile of GoNoodle, and a stakeholder roadmap for implementing evidence-based SEL tools.

## How to Deploy on GitHub Pages

1. Create a new GitHub repository (e.g., `holistic-student-sel`)
2. Upload `index.html`, `styles.css`, and `script.js` to the root
3. Go to **Settings → Pages → Source → Deploy from branch → main / root**
4. Your site will be live at `https://yourusername.github.io/holistic-student-sel/`

## Technologies

- **HTML5** — Semantic structure, accessibility attributes
