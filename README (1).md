## About

This ePublication explores the Social-Emotional Learning (SEL) industry — from its ancient roots to its evolution into a multi-billion dollar technology-driven sector. It features an in-depth historical timeline, current market trend analysis, future industry predictions, a business profile of GoNoodle, and a five-step stakeholder roadmap.

## Features

- **Dropdown navigation** — Industry Analysis expands to reveal Timeline, Trends, and Future Predictions sub-pages
- **Scroll animations** — Timeline entries, cards, and stats animate in as you scroll
- **Animated stat counters** — Market figures count up on the homepage
- **References manager** — Search, filter by section, and add new citations directly on the page; new entries are saved in the browser
- **Fully responsive** — Mobile hamburger menu with touch-friendly dropdown
- **Self-contained files** — All CSS and JavaScript is embedded inside each HTML file; no external dependencies beyond Google Fonts

1. Upload all 9 `.html` files to the **root** of your repository
2. Go to **Settings → Pages → Source → Deploy from branch**
3. Set branch to `main` and folder to `/ (root)`
